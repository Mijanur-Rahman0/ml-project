## Problem Idea

This project investigates the relationship between students’ study habits, attendance, and academic performance. The main objective is to use a small educational dataset to analyze student behavior and develop a basic machine learning model for predicting academic performance. Through this project, fundamental concepts of data preprocessing, data analysis, visualization, model training, and performance evaluation are explored.

## Current Dataset Status

A sample student dataset is being used for initial exploration and laboratory activities. Data inspection and basic analysis have been completed. Additional datasets may be added in future stages of the project.

## How to Run the Notebook

1. Clone the repository.
2. Install the required packages listed in `requirements.txt`.
3. Open the notebook located in the `notebooks` folder.
4. Run all cells in Google Colab or Jupyter Notebook.
